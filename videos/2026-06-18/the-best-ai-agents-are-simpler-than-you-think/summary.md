## 一句話總結
Sierra 產品負責人 Zack Reno Wedeen 解析「最好的 AI agent 其實比你想像中更簡單」——靠扎實的 context engineering、模組化架構與單一 agent 設計，而非堆疊複雜的多 agent 系統，並闡述語音、付款與成效計價如何推動 agentic commerce。

## 重點摘要
- **Sierra 不只是客服平台**：它是涵蓋瀏覽、購買、選位、忠誠、客服等「客戶生命週期所有關鍵時刻」的完整互動平台，部分 agent 甚至以成交抽佣（outcome-based pricing）方式運作。
- **三段式無程式碼建構流程**：平台分為 Analyze（Explorer 深度分析、monitors）、Build（Ghostwriter 寫 agent、Journeys 自然語言 SOP）、Release（治理與變更管理）；日常迭代以「分析→建構→發布」循環為主。
- **Journeys 為核心抽象層**：以宣告式自然語言描述 agent 行為，可與 Agent SDK 程式碼「同構地」雙向轉換；Ghostwriter 直接撰寫 Journeys 而非程式碼，便於事後檢視。
- **遷就模型 vs. 教會模型**：80% 情況應「在模型擅長的地盤上（檔案系統、git、grep）迎合它」，僅在特殊情境才投資讓模型學會自家抽象。
- **一次對話呼叫 10～15 個模型**：混用前沿模型（負責主要推理，1～2 次推論）、分類器與自家微調模型，並大量採用「推測執行」（邊分類邊回應、預先取回知識）。
- **語音是最大差異點**：受 1～2 秒延遲限制，需高度平行化；關鍵突破是「平行化思考、聆聽、說話」，並用 ensembling 同時跑多個轉錄模型（例如某模型轉錄北英格蘭口音最準但靜音時易幻覺，就用另一模型判斷靜音）。
- **付款自建獨立基礎設施**：因無 LLM 供應商通過 PCI 認證，Sierra 建立隔離叢集（付款資訊不送進外部 LLM），取得 PCI DSS Level 1 認證，成為唯一不需轉接的語音付款平台。
- **對多 agent 系統持保留態度**：多數情況「不如想像中有用」，拆分常導致 triage 與執行互相剝奪上下文而破壞價值；除非任務真正可分離，否則靠更好的 context engineering 用單一 monolith 解決。
- **記憶為一級原語**：可隱性／顯性儲存並於回訪時提取，明顯提升解決率與轉換率；但記憶與「身份驗證」綁定，這也是純記憶新創難以做大的原因。
- **成效計價對齊雙方誘因**：「如果你不懂成效計價的價值，代表你的成效大概不值錢」；高價值成交適合抽佣，商品化的問答則走用量／席次計價。

## 關鍵結論／takeaways
- **優先迎合模型既有能力**：把資料具體化成檔案系統、git、grep 等結構，只在無法套用時才投資讓模型學會自家抽象——這是降低 agent 開發難度的核心心法。
- **先做好 context engineering，再考慮多 agent**：「給 agent 它需要的一切，但不多餘」；多數品質問題用更好的上下文管理就能解，多 agent 常是過早優化或在「複製組織架構」。
- **遇到模型「變笨」先檢討自己**：幻覺多半源自 prompt 前後矛盾；prompt compaction 要避免「有損」，用漸進式揭露（progressive disclosure）在相關時才引入內容。
- **語音 agent 要重新思考「何時說話」**：別讓「決定何時說」只用 50 行 VAD、「決定說什麼」卻用兆級參數；思考、聆聽、說話應平行進行。
- **保持模型／供應商無關（model-agnostic）**：用跨模型通用的優質 evals 與 simulations，就能在相近智能等級的模型間低成本切換；多供應商支援也是為了 Black Friday 等尖峰的「容量」韌性，不只成本。
- **品質優先於 prompt caching 與成本**：當成效夠值錢（如成交 $1,000 終身價值方案），不必當快取的狂熱信徒，需要時就打破快取插入正確上下文。
- **RL 適用於「自家正在推進 SOTA」之處（如知識檢索）**；若非如此，前沿模型進步太快，RL 往往是相對無謂的投入，且須防範資料外洩（regurgitation）風險。
- **agentic commerce 將大於 e-commerce，但現在仍非常早期**：連講者本人都還沒用 Codex 訂衛生紙；「自動取消未使用訂閱」這類服務可能最先普及。
- **未來理想人才是「多領域複合型」**：兼具客戶直覺、能動性（agency）、產品判斷與技術深度；coding agent 讓寫程式變快，反而讓產品判斷成為瓶頸、需求更高（F1 賽車比 Hyundai 更常進站換胎）。
